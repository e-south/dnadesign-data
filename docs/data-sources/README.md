# Data Sources

The clean-room public tree retains only the source matrices required by its
published motif bundles.

| Source family | Contents |
| --- | --- |
| JASPAR 2026 CORE | Count and probability matrices used by the 16 fresh and 9 development model exports. |
| HOCOMOCO 14 CORE | Probability matrices used by the MAX, MYCN, and SP1 development exports. |
| [Folder organization](folder-organization.md) | Public source placement and local-only adapter boundaries. |
